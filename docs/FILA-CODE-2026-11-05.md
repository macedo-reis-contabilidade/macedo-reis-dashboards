## 2. A rodada sem enviar
1. `py -3 -m ponte rodar --sem-enviar --meses 3 --saida dominio-v2.json` (o arquivo cai em `C:\ponte-dominio\`). Anote a hora do
   começo e do fim (o log do dia tem as duas) e a linha "lido: …" — ela não pode ter "faltou"; se tiver, anote o bloco
   e o motivo.
2. Só contagens do arquivo (em 09/2026, o último mês com a apuração fechada):
   ```
   py -3 -c "import json; p=json.load(open(r'C:\ponte-dominio\dominio-v2.json', encoding='utf-8')); m=[l for l in p['mensal'] if l['competencia']=='2026-09']; q=lambda c: sum(1 for l in m if (l[c] or 0)>0); print('versao', p['versao'], '| linhas', len(p['mensal']), '| em 09/2026: receita', q('receita_bruta'), '| apuracao do Simples', sum(1 for l in m if l['receita_simples'] is not None), '| compras', q('compras'), '| salarios', q('salarios'), '| pro-labore', q('pro_labore_valor'), '| fgts', q('fgts'))"
   ```
   Anote a linha que ele mostra (são só contagens).
3. Apague o arquivo: `Remove-Item C:\ponte-dominio\dominio-v2.json` (tem nome e CNPJ dos clientes).

## 3. Instalar
Da pasta do repositório (como na instalação: `powershell` como administrador, se ele pedir):
```

```
Anote a última linha que ele mostra. Ele copia a ponte nova pra `C:\ponte-dominio\app` e mantém o `config.ini`.

## 4. A primeira rodada de verdade
1. `Start-ScheduledTask -TaskName 'Ponte Domínio'` e espere ela terminar:
   `Get-ScheduledTaskInfo -TaskName 'Ponte Domínio' | Format-List LastRunTime, LastTaskResult` (o `LastTaskResult` 0 é
   sucesso; a rodada leva uns minutos — repita até o `LastRunTime` ser o de agora e o resultado sair).
2. No log do dia (`C:\ponte-dominio\logs\<hoje>.log`), anote a linha "lido: …" e a do envio ("rodada …: foi (HTTP
   200)"). Se o sistema recusou alguma linha, o log diz quantas e o campo: anote só isso.
