   ```

   ```

3. Apague o arquivo: `Remove-Item C:\ponte-dominio\dominio-v2.json` (tem nome e CNPJ dos clientes).

## 3. Instalar
Da pasta do repositório (como na instalação: `powershell` como administrador, se ele pedir):


## 4. A primeira rodada de verdade
1. `Start-ScheduledTask -TaskName 'Ponte Domínio'` e espere ela terminar:
   `Get-ScheduledTaskInfo -TaskName 'Ponte Domínio' | Format-List LastRunTime, LastTaskResult` (o `LastTaskResult` 0 é
   sucesso; a rodada leva uns minutos — repita até o `LastRunTime` ser o de agora e o resultado sair).
2. No log do dia (`C:\ponte-dominio\logs\<hoje>.log`), anote a linha "lido: …" e a do envio ("rodada …: foi (HTTP
   200)"). Se o sistema recusou alguma linha, o log diz quantas e o campo: anote só isso.
