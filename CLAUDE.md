# Macedo & Reis — Dashboards · Guia pro Claude Code

Sistema interno de gestão do escritório **Macedo & Reis Contabilidade** (Três Coroas/RS).
**Stack:** HTML + JS vanilla multi-página, Supabase (auth + dados), jsPDF pra documentos. **Sem framework, sem build, sem npm** — o que está no repo é o que vai pro ar.
**Deploy:** GitHub Pages, branch `main`, raiz. Build automático a cada push (~30s; cache Fastly — testar com `?nocache=1`).

- ⚠ **Conector do Supabase:** comando que ele julga destrutivo (DELETE, DROP, TRUNCATE, UPDATE sem WHERE) pede uma confirmação que este app não mostra — volta `{"status":"cancelled"}`. Ele corta o SQL em todo `;`, inclusive dentro de texto: `update ... set regra = 'a; b' where ...` vira "UPDATE sem WHERE". Textos gravados pelo conector vão sem `;` (usar ` · `). Apóstrofo solto no texto de um UPDATE (número ímpar de `'`) dá o mesmo cancelamento — ele acha que o WHERE ficou dentro do texto. Texto longo (leitura de material): marcador no lugar do `;` e do `'`, devolvidos com `replace(..., chr(59))` e `chr(39)`, em partes de ~7 mil caracteres (INSERT e depois `update ... set leitura = leitura || ... where codigo = ...`), conferindo no fim com `md5(leitura)`. A transcrição do SQL troca o espaço sem quebra (o do "R$ 1.234,56" que o `toLocaleString` põe) por espaço comum e converte barra invertida + `u` + 4 dígitos no próprio caractere: o espaço sem quebra vai com marcador, devolvido com `chr(160)`, e o texto vai sem barra invertida (14/10/2026). Simulações gravadas pelo banco: o `sim_obs` mantém a ordem de chaves que a página grava (montado pelo tipo `json`, não `jsonb`), senão o próximo "Refazer simulações" não as reconhece como iguais.
